🚀 Live Shareable Deployment Instructions

How this project is deployed to Vercel for instant sharing, and to Streamlit Community Cloud for native Python hosting.

SHARABLE WEB APP

▲ Deploy to Vercel (This Website)

Zero-config deployment hosting the responsive in-browser Computer Vision suite with WebGL hardware acceleration.

  1. Install the Vercel CLI: npm i -g vercel
  2. Log in to your account: vercel login
  3. Inside this project directory, run: vercel
  4. Select Y to accept defaults. Vercel automatically deploys web/ using vercel.json!
  5. Your live shareable URL is generated: https://visionai-<your-username>.vercel.app
> vercel --prod
FULL PYTHON BACKEND

☁️ Deploy to Streamlit Community Cloud

Snowflake's free native cloud hosting running the full Python stack (PyTorch, YOLOv8n, YuNet, SFace, and SQLite).

  1. Push this repository to your GitHub account: git push origin master
  2. Visit share.streamlit.io and sign in with GitHub.
  3. Click "New App" and select your VisionAI repository.
  4. Set main file path to: app/app.py
  5. Click "Deploy"! In ~2 minutes, your permanent Python app is live at https://visionai.streamlit.app.
